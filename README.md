## 🔍 Understanding the Model Process

The software uses a technique called Localization-Grounded Supervision. This process links identifying text to specific pixels in an image. Instead of checking an entire image at once, the software looks for patterns in specific regions. This increases the reliability of the output. 

The model acts as a guide. It points you toward areas that require closer inspection. Use these pointers to conduct your review. This software does not replace clinical judgment. It serves as a tool to assist your diagnosis. You remain the final authority on all findings.

## 📁 Data Privacy and Security
